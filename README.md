## Create Your First GitHub Project

If you're new to GitHub, follow these steps:

1. Create a GitHub account at [github.com](https://github.com).
2. Click **New repository** (from the top-right **+** menu).
3. Enter a repository name (example: `my-first-project`).
4. Add a short description (optional).
5. Choose **Public** (or **Private**, if you prefer).
6. Check **Add a README file**.
7. Click **Create repository**.

### Add your first file

8. Click **Add file → Create new file**.
9. Name the file (example: `hello.txt`).
10. Add text like: `Hello GitHub!`
11. Click **Commit new file**.

### Next step

After this, you can upload code from your computer using Git (Windows/Mac/Linux).
